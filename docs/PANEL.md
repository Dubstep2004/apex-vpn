# Панель APEX VPN (Telegram-бот)

Бот работает бесплатно на Cloudflare Workers и умеет:

- **📦 Обновления** — после каждой сборки на GitHub бот присылает «Новая сборка 1.x.x» с кнопками
  «Опубликовать», «Обязательное обновление», «Пропустить». После публикации приложения сами предложат обновиться.
- **📢 Объявления** — `/news Заголовок⏎текст` или `/warn …` (жёлтое); `/news_off` убирает.
- **🛠 Техработы** — `/maintenance текст` показывает баннер, `/maintenance_off` убирает.
- **🐞 Сбои** — отчёты о падениях приложения приходят сразу; `/crashes` — последние.
- **✉️ Сообщения** — «Настройки → Сообщить о проблеме» в приложении приходит вам в бот.
- **📊 Статистика** — `/stats`: сколько устройств за сутки, неделю и месяц и какие у них версии.

Секреты задаются один раз, дальше всё обновляется само при каждой сборке.

## Настройка (один раз, ~10 минут)

### 1. Бот в Telegram
1. Откройте **@BotFather** → `/newbot` → придумайте имя → получите **токен** вида `123456:ABC…`.
2. Узнайте свой **ID**: напишите **@userinfobot**, он ответит числом.

### 2. Cloudflare (бесплатно)
1. Зарегистрируйтесь на **dash.cloudflare.com**.
2. Откройте **Workers & Pages** один раз — Cloudflare предложит выбрать адрес `*.workers.dev`, согласитесь.
3. Справа на главной странице аккаунта скопируйте **Account ID**.
4. **My Profile → API Tokens → Create Token → шаблон «Edit Cloudflare Workers» → Continue → Create Token**,
   скопируйте токен.

### 3. Секреты в GitHub
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Name | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_ADMIN_IDS` | ваш ID (несколько — через запятую) |
| `CLOUDFLARE_API_TOKEN` | токен Cloudflare |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID |
| `APEX_KEYSTORE_BASE64` | ключ подписи (из файла `apex-keystore-secrets.txt`) |
| `APEX_KEYSTORE_PASSWORD` | пароль ключа (оттуда же) |

### 4. Сборка
**Actions → Build APEX VPN → Run workflow**. Через ~25 минут бот пришлёт «Новая сборка» — нажмите «Опубликовать».

> Сборку с панелью нужно один раз установить вручную (APK со страницы **Releases**), предварительно удалив старую
> версию: прежние сборки были подписаны временными ключами. Дальше обновления ставятся из приложения.

## Как это устроено
- `panel/worker.js` — код бота и сервера обновлений; `panel/deploy.sh` разворачивает его через API Cloudflare.
- APK хранится в Cloudflare KV частями по 20 МБ (держим 3 последние сборки), поэтому обновления работают
  и при **приватном** репозитории.
- Приложение берёт `update.json`, `news.json`, отправляет `/crash`, `/ping`, `/feedback` на адрес панели —
  его CI подставляет при сборке сам.
- Бесплатных лимитов Cloudflare (100 000 запросов и 1 000 записей в сутки) хватает на тысячи пользователей.
