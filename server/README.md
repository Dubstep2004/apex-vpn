# Сервер APEX VPN (ваш VPS)

> [!NOTE]
> **Обновления приложения приходят с GitHub Releases** — сервер для них не нужен.
> Сервер нужен для **объявлений** на главном экране, **отчётов о сбоях** и страницы для скачивания.

## Установка (Ubuntu / Debian)

```bash
curl -fsSL -o apex https://raw.githubusercontent.com/Dubstep2004/apex-vpn/main/server/apex && sudo bash apex
```

В меню выберите **1** и введите домен (A-запись домена должна указывать на IP сервера).
Скрипт поставит Caddy с бесплатным сертификатом и напечатает адрес сервера, например
`https://vpn.ваш-домен.ru/apexvpn`.

Чтобы приложение отправляло на него отчёты о сбоях и брало объявления, добавьте адрес в GitHub как переменную
`SERVER_URL` (**Settings → Secrets and variables → Actions → Variables**) и пересоберите. Без неё всё остальное работает.

Если порт 443 занят VPN-сервером, сайт поднимется на 8443 — адрес будет с `:8443`.

## Меню

Наберите **`sudo apex`**:

```
   1. Установить / переустановить
  ── Объявления и сбои
   2. Опубликовать объявление
   3. Убрать объявление
   4. Отчёты о сбоях
   5. Удалить отчёты о сбоях
  ── Наблюдение
   6. Состояние и ссылки
   7. Сводка: устройства и версии
   8. Здоровье сервера
  ── Управление
   9. Резервная копия (ключ и настройки)
  10. Восстановить из копии
  11. Сертификат и домен
  12. Сменить домен
  13. Журналы
  14. Обслуживание сейчас
  15. Ключ подписи для GitHub
  16. Проверить обновления скрипта
  17. Удалить сервер APEX
   0. Выход
```

- **Сводка (7)** — сколько устройств с приложением заходили за новостями и какие у них версии (по IP; журнал хранится 7 дней).
- **Обслуживание** идёт само раз в неделю: перезапускает упавшие службы, проверяет сертификат и диск, удаляет старые отчёты, обновляет скрипт. Итог — в шапке меню.
- **Ключ подписи для GitHub (15)** — покажет два значения для секретов GitHub `APEX_KEYSTORE_PASSWORD` и `APEX_KEYSTORE_BASE64`. Тогда все сборки подписаны одним ключом навсегда.
- **Страница сервера** `https://ДОМЕН/apexvpn/` ведёт на последнюю версию на GitHub.

## Команды без меню

| команда | что делает |
|---|---|
| `apex news "Текст" --title "Заголовок"` | объявление (`--warning` — жёлтое, `--url` — ссылка) |
| `apex news off` | убрать объявление |
| `apex crashes 20` / `apex crashes clear` | последние отчёты о сбоях / удалить все |
| `apex status` | адрес, последняя версия на GitHub, объявление |
| `apex stats 7` | сводка за 7 дней |
| `apex health` | нагрузка, память, диск, службы, сертификат |
| `apex maintain` | обслуживание прямо сейчас |
| `apex backup` / `apex restore файл` | резервная копия ключа и настроек / восстановление |
| `apex cert` / `apex logs` | сертификат / журналы |
| `apex github-key` | ключ подписи для секретов GitHub |
| `apex update-script` / `apex uninstall` | обновить скрипт / удалить сервер APEX |

## Файлы

- `install.sh` — установка (Caddy с https, приём сбоев, ключ подписи, команда `apex`)
- `apex` — меню и команды
- `crash-receiver.py` — приём отчётов о сбоях (только 127.0.0.1, наружу через Caddy)
- `news.json` — пример объявления
